## Fluxio 0.1.0 — first release

Transfer files between your Windows PC and your phone with a QR code, over your local network. No cable, no account, no cloud upload, no app on the phone.

### Downloads

| File | What it is |
|---|---|
| `FluxioSetup-0.1.0.exe` | Installer (recommended). Installs for your user without admin rights; "all users" install can also add a Windows Firewall rule for private networks. |
| `Fluxio-0.1.0-win-x64.zip` | Portable version: unzip and run `Fluxio.exe`. |
| `SHA256SUMS.txt` | SHA-256 checksums of the files above. |

Requirements: Windows 11 or Windows 10 (64-bit). .NET is included. Phone: Android or iPhone with an up-to-date browser, on the same Wi-Fi.

> **Not code-signed yet.** Windows SmartScreen may show “Windows protected your PC”. Check the SHA-256 checksum (`Get-FileHash FluxioSetup-0.1.0.exe`), then choose *More info › Run anyway*.

### What's in it

- QR code pairing with one-time, expiring codes; approve the phone with a matching 4-digit code.
- Computer → phone and phone → computer in one session, many files at once, drag and drop of files and folders.
- Approval of incoming files with name-conflict handling (keep both, replace, skip).
- Chunked, resumable uploads; streaming, resumable downloads; SHA-256 verification on both sides.
- Transfers page with real speed and time remaining; local history; settings; Turkish and English; dark and light themes.
- Diagnostics for the Windows network profile and Windows Firewall, with a one-click rule for private networks.

### Known limitations

- Both devices must be on the same local network (no transfers over the internet yet).
- The connection inside the network uses HTTP — use trusted networks. See the security model in `docs/security.md`.
- Downloads to the phone above 1 GB (512 MB on iPhone) use the browser's download manager and are not verified by the page.
- Transfers stop if the phone locks or the browser goes to the background.
- Tested on Windows 11. Computer → phone was tested with a real phone; phone → computer is covered by automated end-to-end tests of the protocol but not yet by a real-device run. Please report issues.
