Release notes

Published builds and their files are on GitHub Releases.

0.1.0 — first version (not published yet)

  • QR code pairing with one-time, expiring codes and device approval with a matching code.
  • Computer → phone and phone → computer transfers in one session, several files at once.
  • Chunked, resumable uploads from the phone; streaming downloads with resume; SHA-256 verification on both sides.
  • Approval of incoming files with name-conflict handling (keep both, replace, skip).
  • Transfers page with real speed and time remaining, local history, settings, Turkish and English, dark and light themes.
  • Network diagnostics for Windows network profile and Windows Firewall.

Known limitations

  • Both devices must be on the same local network; transfers over the internet are not available yet.
  • The connection inside the network uses HTTP (see Security).
  • Very large downloads to the phone use the browser's download manager and are not verified by the page.
  • Builds are not code-signed yet.
