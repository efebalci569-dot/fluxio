Release notes

Installation

  • Installer (FluxioSetup-x.y.z.exe): installs for your user or all users, adds a Start menu entry and, if you choose, a Windows Firewall rule for private networks.
  • Portable (Fluxio-x.y.z-win-x64.zip): unzip and run Fluxio.exe. Windows asks once whether Fluxio may use the network — allow it on private networks.
  • Fluxio is not code-signed yet. SmartScreen may show “Windows protected your PC”. Verify the SHA-256 checksum, then choose “More info” › “Run anyway”.
  • Fluxio never needs administrator rights to run.

On your phone

Nothing to install. Scan the QR code shown by Fluxio with the camera app.

Build from source

Requires the .NET 10 SDK and Node.js 20+. Clone the repository and run scripts/build.ps1; see docs/development.md.
