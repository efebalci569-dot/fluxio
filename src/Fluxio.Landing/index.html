01How it works

Three steps. No cable.

Your computer and phone just need to be on the same Wi-Fi or local network.

  1. 01
    Send files Receive files

    Open Fluxio on your computer.

    Choose Send Files or Receive Files. Fluxio starts a short-lived session and shows a QR code.

  2. 02
    PC4271 Phone4271

    Scan the QR code with your phone.

    Your camera opens the Fluxio page in the browser. Confirm the 4-digit code on your computer to allow the phone.

  3. 03
    JPG MP4 PDF SHA-256 verified

    Select files and transfer.

    Pick files on either device. The other side accepts, the files stream across, and both sides verify them.

03Security

Designed so only your phone gets in.

Fluxio does not trust every device on your network. Access is short-lived, explicit and limited to what you choose to share.

Read the security model

  1. 01One-time, expiring QR codes

    256-bit random secret, usable by a single phone, valid for minutes. A new code invalidates the old one.

  2. 02You approve the phone

    A matching code appears on both screens before anything can be transferred.

  3. 03Approve incoming files

    Nothing is written until you accept. Existing files are never overwritten without asking.

  4. 04SHA-256 verification

    A transfer only counts as complete after both sides agree on the checksum.

  5. 05Local network only, only while needed

    The service listens on one LAN address and only during a session. Files are never opened or run.

*Good to know

Inside your network Fluxio uses plain HTTP (your Wi-Fi encryption protects it over the air), because phone browsers cannot trust a local certificate without warnings. Use Fluxio on networks you trust.

04Requirements

What you need

Computer

Windows 11 or Windows 10 (64-bit). No separate .NET installation needed.

Phone

Any Android or iPhone with a camera that reads QR codes and an up-to-date browser (Chrome, Safari, Samsung Internet, Firefox).

Network

Both devices on the same Wi-Fi or local network. Guest networks with “client isolation” block device-to-device traffic.

05FAQ

Questions

Do I need to install an app on my phone?

No. The QR code opens the Fluxio page in your phone's browser.

Does it work over the internet?

Not in this version. Both devices must be on the same local network. Transfers between different networks are planned for a later version and will be clearly explained before they are offered.

Where are files saved on my phone?

Your phone's browser decides — usually the Downloads folder, or Files › Downloads on iPhone. A web page cannot pick a folder.

Is there a size limit?

Up to 100 GB per file and 500 files per transfer. Very large downloads to the phone (over 1 GB, 512 MB on iPhone) use the browser's own download manager, which Fluxio cannot verify on the phone.

Why does Windows warn when I run the installer?

The first releases are not code-signed yet, so SmartScreen may show a warning. Download only from the official GitHub releases and compare the SHA-256 checksum shown on the download page.

Is Fluxio free?

Yes. Fluxio is open source under the MIT license.
